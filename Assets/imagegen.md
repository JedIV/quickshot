# Icon source

Generated with the built-in ImageGen tool. `Quickshot.png` is the original artwork; `Quickshot.icns` contains the standard macOS icon sizes. Rebuild the icon bundle with `./scripts/build-icon.sh`.

## Prompt

Create one polished, cute macOS app icon for Quickshot, a tiny fast screenshot annotation app. No words, letters, numbers, captions, or watermark. A chunky cherry-coral red and warm-white bullseye target with softly rounded concentric rings, a short little arrow planted exactly in the center, arrow pointing diagonally down-left into the target from the upper-right with small mint-teal fletching. Friendly, playful, clean and restrained, not a complex illustration. Slightly dimensional soft enamel / molded clay finish with very subtle shading, crisp smooth edges and strong readable silhouette at small sizes. Center the target on a warm ivory macOS rounded-square tile with a delicate soft shadow; the tile fills about 86% of the square canvas. The exterior outside the rounded tile must be genuinely transparent. Front-facing target, simple balanced composition. One icon only, not a presentation sheet, no mockup, no surrounding UI.
